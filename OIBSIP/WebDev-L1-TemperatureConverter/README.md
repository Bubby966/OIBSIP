# Temperature Converter

## Overview
This project is a professional and beginner-friendly temperature converter website that converts values among Celsius, Fahrenheit, and Kelvin while validating input and absolute-zero limits.

## Features
- Numeric temperature input
- Unit selector for Celsius, Fahrenheit, and Kelvin
- Convert and clear buttons
- Real-time result display
- Input validation and absolute-zero checks
- Responsive design for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive web design
