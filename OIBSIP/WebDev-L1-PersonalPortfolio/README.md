# Thatha Rakesh Portfolio

## Overview
This project is a personal portfolio website for Thatha Rakesh, a B.Tech Computer Science student specializing in Artificial Intelligence and Machine Learning. It highlights his education, skills, projects, and contact details.

## Features
- Sticky navigation bar
- Hero section with name and role
- About section
- Skills grid
- Project cards
- Education section
- Contact form with JavaScript validation
- Responsive layout for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive design
