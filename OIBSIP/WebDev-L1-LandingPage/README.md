# AGROVISION Landing Page

## Overview
This project is a responsive landing page for AGROVISION, an AI-powered smart agriculture platform designed to help farmers make better crop, soil, and weather decisions using technology.

## Features
- Sticky navigation bar
- Hero section with strong call-to-action buttons
- Feature cards for AI farming tools and services
- How It Works section
- About/mission section
- Contact section with social placeholders
- Responsive design for mobile, tablet, and desktop

## Technologies Used
- HTML5
- CSS3
- Flexbox and CSS Grid
- Responsive web design
